# RhizoChip


**RhizoChip: A modular 3D-printable in situ co-culture device for studying microbial interactions in soil and plant-associated systems**


## Overview

RhizoChip is a modular 3D-printable device designed for the controlled co-culture of microbial communities under laboratory and soil-associated conditions.

The device allows spatial confinement of microbial populations while enabling the exchange of diffusible metabolites through permeable membranes. This architecture supports the study of microbial interactions, community assembly, and the identification of functional consortia with potential applications in sustainable agriculture.

The design is implemented as a parametric OpenSCAD model, allowing users to modify the number of modules, rows, wells, dimensions, ports, and other structural features directly from code.

## Repository contents

- [`scad/`](scad/)  
  Parametric OpenSCAD design files used to generate the device geometry.

- [`stl/`](stl/)  
  Exported STL files for selected device configurations.

- [`docs/`](docs/)  
  Technical documentation describing the design, fabrication workflow, validation stage, and intended applications of the device.
